# Learning Journey
> 从一个普通人，到一个工程师的成长记录

这里没有天赋异禀的传奇，只有一步一个脚印的积累。
每一行代码、每一篇笔记、每一次踩坑，都是这条路的见证。

---

## 🌱 起点
非天才，非保送，只是一个普通人。
和所有人一样，从Hello World开始，
从看不懂指针、写不出递归、调不通接口开始。

---

## 📍 这条路在走什么

### 语言从入门到能干活
- C：从语法到理解内存
- Java：从面向对象到能写后端
- Python：从脚本到数据处理

### 算法从怕写到刷到停不下来
- LeetCode
- 洛谷
- 从暴力解到优化解

### 计算机从会用电脑到理解电脑
- 操作系统到底在干嘛
- 网络数据怎么跑起来的
- CPU和内存之间发生了什么

### 工程从写代码到做项目
- Git怎么用
- 项目怎么组织
- 代码怎么写得不烂
